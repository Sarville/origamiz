# Сессия 2026-09-25 22:11 — Android/RuStore, чанк 1

## Итог
Изучен вопрос порта под Android для RuStore (чек-лист `yandex-vk-integration`, раздел 11; референс — flowit/Colorit).
Реализован чанк 1: билд-вариант `android` + нативная оболочка Capacitor + платформенная обёртка. Debug-APK собран
(JDK 21) и проверен на эмуляторе `colorit`: игра стартует, баннер РСЯ (демо) показывается сверху, «назад» в главном
меню не закрывает приложение, RuStore Pay SDK инициализируется и отвечает `Application not found`
(ожидаемо: `rustoreConsoleAppId=0`), ошибка перехвачена.

## Что сделано
- `gulp/build_variants.js`, `gulp/js.js` — вариант `android`, define `G_IS_ANDROID` и `G_YAN_{BANNER,INTERSTITIAL,REWARDED}_ID`
  (из env `YAN_*_ID`, по умолчанию демо-блоки Яндекса, которые не платят).
- `src/js/platform/android_wrapper.js` — `PlatformWrapperImplAndroid`: RuStore Pay (`disable_ads` non-consumable,
  `currency_pack_10k` consumable, acknowledge после выдачи, докредит незавершённых при старте), Yandex Mobile Ads
  (баннер сверху, предзагружаемый интерстишл, rewarded).
- `src/js/application.js`, `globals.d.ts`, `states/ingame.js` — выбор обёртки, pause-on-focus-lost для android.
- `android/` — сгенерирован штатным `cap add android` (applicationId `ru.sarville.origamiz`), + RuStore Pay 10.5.0,
  `RuStorePayPlugin.java`, `MainActivity.java` (deeplink `origamizpay`, back → Escape), signing через
  `keystore.properties` (gitignored, вместе с `*.jks`).
- `capacitor.config.json`, `package.json` (`build-android`, зависимости Capacitor + `@quenary/capacitor-yandex-ads`).
- `docs/android-rustore.md` — сборка, карта кода, чек-лист до первого релиза.

## Находки
- Capacitor-плагин — Proxy: возврат `YandexAds` из `async`-функции падает с `"YandexAds.then()" is not implemented`.
  Инициализация возвращает `void`, плагин используется напрямую.
- Копирование `android/` из соседнего проекта flowit было заблокировано политикой — каркас сгенерирован `cap add`.
- Эмулятор надо запускать через `setsid nohup … &`, иначе умирает вместе с фоновой оболочкой.
- `npm run lint` показывает 2 старые ошибки `@ts-ignore` в `application.js:207,209` — не из этой сессии.
