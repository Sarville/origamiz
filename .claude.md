## Dev server access

`npm run gulp` (default task) serves the standalone dev build via browser-sync
on port 3005. Don't hand the user a raw `http://<hostname>.<tailnet>.ts.net:3005/`
link — confirmed unreliable from at least one real phone (large transfers like
the JS bundle stall/drop, only works via a Tailscale exit node). Instead run
`tailscale serve --bg --https=<port> 3005` and give that URL — it routes
through tailscaled's own HTTPS proxy and reliably reaches devices without an
exit node. Check `tailscale serve status` first for already-used ports/URLs
(other services on this machine use this pattern too).

## Testing the game visually in this sandbox

Headless Chrome (`--headless --screenshot=...`) reports `document.hidden = true`,
and the game itself pauses boot/rendering when hidden — this looks like a hang
but isn't a bug. For a real visual check, use Xvfb + non-headless Chrome +
`import -window <id>` (ImageMagick) for the screenshot instead.
