## 2. Single-place brand constants (the "dynamic" mechanism requested)

Three independently-built subsystems (main game bundle, Electron shell, gulp
packaging) each get their own tsc/build project — a single constant can't
safely cross those boundaries (verified: `electron/tsconfig.json` and
`src/tsconfig.json` are separate tsc programs from root `tsconfig.json`;
importing a shared root-level JSON/JS file into either risks tsc `rootDir`
errors on emit). So instead of one universal file, each subsystem got exactly
one canonical constant, consistent with how each already has its own single
config file:

- `src/js/core/config.ts` → `export const APP_NAME = "Origamiz";` — used by
  the console banner (`main.js`), and logo `alt` text (`main_menu.js`,
  `preload.js`, and `about.js` which already used a dynamic
  `THIRDPARTY_URLS.github` replace from a prior session).
- `electron/src/config.ts` → `defaultWindowTitle = "Origamiz"` (was `"shapez
  CE"`).
- `gulp/build_variants.js` → `export const BRAND_NAME = "Origamiz";` —
  consumed by `gulp/standalone.js` (`executableName`, packager `name`,
  `appBundleId`, `appCopyright`) and `gulp/sounds.js` (sound cache dir name).
