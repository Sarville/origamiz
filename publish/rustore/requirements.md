# Требования RuStore Console (копия из справочника скилла yandex-vk-integration)

Консоль: «Загрузка версии приложения», шаги «Технические сведения → Информация → Медиа → Настройки».

Источник: скриншоты консоли от пользователя (2026-09-26) и страница справочника RuStore
`rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/category` (загружается
через WebFetch; часть страниц `rustore.ru/help` отдаёт HTTP 429 скриптам). Шаг «Настройки» (шестерёнка) на скриншотах
не был виден — **TBD**.

### Технические сведения
- **Запрашиваемые данные**: «Типы данных» — выбрать из списка (0/38), какие данные собирает приложение
  (ссылка «Подробнее о типах данных»). Для игры с рекламой и платежами отметить то, что реально собирается
  (рекламные идентификаторы и т.п. — сверять с политикой конфиденциальности; точный список TBD).
- **Интеграции** (необязательно): платёжные (до 20) и рекламные (до 20) SDK; **найденные в файле (AAB) RuStore
  добавляет автоматически, удалить их нельзя** — поэтому лишних SDK в сборке быть не должно. Для нашего стека:
  платёжная **«Rustore SDK pay»** (не «RuStore Billing» — старый SDK мёртв), рекламная **«Yandex Mobile Ads»**.
  Прочие в списках: платёжные — Adapty, Adyen Drop-in, Alipay, Braintree, CloudPayments, PayPal Checkout, Stripe,
  Tinkoff Acquiring, VK pay, WeChat Pay, Xsolla, YooKassa, Яндекс Пэй, «Другая»; рекламные — AdColony, AppLovin MAX,
  Appodeal, BIGO Ads, CAS.AI, Chartboost, Fyber FairBid, Google Mobile Ads (AdMob), IronSource LevelPlay, Meta
  Audience Network, Mintegral, MyTarget, Pangle, Tapjoy, Unity Ads, Verve Group / HyBid, Vungle, «Другая».

### Информация
| Поле | Требования |
|---|---|
| Название для пользователей | можно менять при загрузке новой версии; лимит длины — TBD |
| Тип | «Приложение» (**по умолчанию**) или «Игра» — для игры **выбрать «Игра»**, иначе применятся категории приложений |
| Встроенные покупки | выбор из созданных продуктов, до **3** (нужна одобренная монетизация, продукты создаются заранее) |
| Основная категория | одна; для игр — список ниже |
| Дополнительная категория | необязательно («Нет»); максимум одна; на модерации поддержка может скорректировать выбор |
| Возрастное ограничение | выбор из списка (правила — TBD, отдельный раздел справочника) |
| Поисковые теги | необязательно, до **5**; поисковая выдача обновляется в течение 4 часов, подсказки в поиске — в течение суток |
| Описание для телефонов и планшетов: Краткое | «Расскажите самое главное о приложении»; лимит — TBD |
| Описание: Основное | «Опишите подробно, что есть внутри»; лимит — TBD |
| Способы связи | E-mail, адрес сайта, сообщество ВКонтакте, MAX (для связи пользователей с разработчиком) |
| Часто задаваемые вопросы | необязательно, до **10** пар вопрос–ответ; показываются только на сайте RuStore |

**Категории игр** (19): Аркады, Викторины, Головоломки, Гоночные, Детские, Казино, Казуальные, Музыкальные,
Настольные и карточные, Приключения, Ролевые, Симуляторы, Словесные, Спортивные, Стратегии, Экшен, Шутеры, Платные
(игры с платным доступом, не F2P), Утилиты (эмуляторы, гайды, модификации). Правила: одна основная + одна
дополнительная; «Детские», «Казино» и «Ставки и лотереи» — **без дополнительных категорий**; запрещены реалистичные
сцены жестокости, обилие нецензурной лексики, шокирующий/оскорбительный контент, пропаганда ненависти/дискриминации.
Категории приложений (20) — Бизнес-сервисы, Государственные, Еда и напитки, Здоровье, Книги, Новости и события,
Образ жизни, Образование, Общение, Объявления и услуги, Питомцы, Покупки, Полезные инструменты, Путешествия,
Развлечения, Родителям, Спорт, Ставки и лотереи, Транспорт и навигация, Финансы — для игр не подходят.

### Медиа
| Что | Требования |
|---|---|
| Иконка приложения (мобильные) | JPG или PNG, **до 1 МБ**, пропорции **1:1**, сторона **от 32 до 512 px** (берём 512×512) |
| Скриншоты для телефонов | **минимум 3**, до 10; JPG/PNG, **до 5 МБ**, максимум 3840×2160; пропорции 16:9 (другие обрезаются; итоговая ориентация — 9:16 или 16:9 по первому файлу, поэтому все скриншоты одной ориентации); рекомендуется **JPG 1920×1080**; важное держать в кадре — иначе модерация может отклонить |
| Скриншоты для планшетов | необязательно; если есть — **минимум 3**, до 10; те же требования |
| Видео | необязательно; **ссылка на VK Видео** (не файл): публичный доступ, 16:9 или 9:16, **до 2 минут** |

Не забыть отдельно (не в этих формах): URL политики конфиденциальности, релизный подписанный AAB, ключ подписи
(раздел 11.2 чек-листа), продукты и заявка на монетизацию (11.3/11.5).
