## What shipped (achievements)

- 65 achievements, translated en+ru (`translations/base-en.yaml` /
  `base-ru.yaml`, `achievements:` section). 6 are secret (description hidden
  until unlocked).
- Per user's specific requests: `oldLevel17` renamed to `whoKnows` (no longer
  secret, description now a non-explaining flavor line, triggers on the
  *original vanilla shapez.io logo shape* as a hidden nod); `produceMsLogo`
  renamed to `msLogo` (no longer secret, description = "Hello, Bill!");
  `logoBefore18` stays secret but now triggers on the *new* Origamiz logo
  shape (`RwCu--Wu:----Rw--`), which is also the trigger for the normal
  `produceLogo` achievement.
- New engine signals (`itemStored`, `itemsTrashed`, `blueprintPlaced`) added
  to `root.js` with minimal dispatch points in `belt_path.js`,
  `item_ejector.js`, `item_processor.js`, `blueprint.ts`.
- New HUD part `HUDAchievementTracker` (`src/js/game/hud/parts/
  achievement_tracker.js`) subscribes to root signals, tracks per-save
  progress (serialized via `savegame_serializer.js`, same pattern as
  `HUDWaypoints`/`HUDPinnedShapes`), and unlocks achievements globally
  (forever, independent of savegame) via a new `AchievementsStorage`
  (`src/js/profile/achievements_storage.js`, `achievements.bin`, same
  `ReadWriteProxy` pattern as `ApplicationSettings`).
- New `AchievementsState` (`src/js/states/achievements.js` +
  `src/css/states/achievements.scss`), reachable from a new sidebar button in
  Settings and a new trophy-icon button on the main menu next to the
  settings gear (`src/js/states/main_menu.js`, `src/css/states/
  main_menu.scss`).
- The main-menu trophy icon was generated with `codex exec` (see
  [[codex_cli_asset_generation]]), an inline SVG matching the existing
  settings-gear button's warm cream/gold palette with paper-fold-style
  facets on the cup and base.
